# 抖音核污水事件传播因果分析报告

## 1. 数据概况

- **原始数据**: 294条视频, 18,883条评论
- **时间窗口**: 12小时
- **有效时间点**: 66个
- **发现因果关系**: 75个显著关系 (p < 0.05)

## 2. 核心发现

### 2.1 瞬时传播网络 (Lag 0)

**发现**: 用户互动行为呈现强同步性

| 因果关系 | 相关性 | 传播意义 |
|----------|--------|----------|
| 点赞 ↔ 评论 | **0.99** | 点赞和评论几乎同时发生 |
| 转发 ↔ 收藏 | **0.95** | 深度互动行为同步 |
| 点赞 ↔ 转发 | **0.89** | 认可后立即传播 |
| 评论 ↔ 转发 | **0.87** | 讨论驱动分享 |

**传播机制**: 
- ✅ **级联效应**: 一个互动行为触发多个连锁反应
- ✅ **情绪共振**: 核污水话题的强情绪性导致即时反应
- ✅ **算法放大**: 抖音推荐算法识别高互动内容并即时推送

---

### 2.2 反馈循环: 互动驱动内容生产

#### 短期反馈 (12小时)

```
转发(t-1) --[0.38]--> 视频发布(t)
评论数(t-1) --[0.41]--> 视频发布(t)
```

**解释**: 
- 前12小时的转发和评论活跃度,刺激创作者在下一个12小时发布新内容
- **创作激励机制**: 热度 → 流量 → 创作动力

---

#### 中期发酵 (24小时)

```
评论数(t-2) --[0.53]--> 视频发布(t) ⭐最强
评论质量(t-2) --[0.46]--> 视频发布(t)
```

**解释**:
- 24小时前的优质讨论,形成话题热度
- 创作者观察到话题价值,跟进发布相关内容
- **议程设置效应**: 评论引导创作方向

---

#### 长期影响 (36小时)

```
点赞(t-3) --[0.39]--> 视频发布(t)
收藏(t-3) --[0.42]--> 视频发布(t)
```

**解释**:
- 36小时前的高赞/高收藏内容,通过推荐算法持续影响
- 创作者分析爆款特征,模仿成功案例
- **模因传播**: 成功内容格式被复制
